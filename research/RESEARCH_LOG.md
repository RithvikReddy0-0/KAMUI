## How to add an entry

1. Create a folder: `research/experiments/exp_NNN_short_description/`
2. Copy the template from `research/experiments/README.md`
3. Fill in `config.yaml`, `results.json`, and `notes.md`
4. Add a row to the table above

## Status codes

| Code | Meaning |
|------|---------|
| ✅ confirmed | Hypothesis supported by evidence |
| ❌ refuted | Hypothesis contradicted by evidence |
| 🔄 in progress | Experiment running |
| ⏸ paused | Deprioritised, may resume |
| ❓ inconclusive | Evidence mixed or insufficient |
